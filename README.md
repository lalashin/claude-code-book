# Claude Code 실전 입문서

> 비개발자부터 심화 사용자까지 — Claude Code를 제대로 활용하는 법

**[📖 책 뷰어로 읽기](https://lalashin.github.io/claude-code-book/book_viewer/)**

---

## 소개

Claude Code를 처음 접하는 분부터 에이전트·훅까지 활용하는 심화 사용자를 위한 실용 입문서입니다.  
이 책 자체도 Claude Code 에이전트 팀으로 집필·편집·시각화되었습니다.

## 목차

| 챕터 | 제목 | 핵심 내용 |
|------|------|----------|
| 1 | 설치부터 첫 대화까지 | Native 설치, Windows/Mac, 첫 실행 |
| 2 | AI에게 잘 말하는 법 | 3박자(맥락·목표·제약), @멘션, Esc |
| 3 | 파일과 폴더 다루기 | 읽기·생성·수정, 승인 프롬프트 |
| 4 | 첫 결과물 만들기 | HTML 웹페이지, 루프 패턴 |
| 5 | 코드베이스 탐색 | Plan 모드, CLAUDE.md |
| 6 | 슬래시 명령과 MCP | 커스텀 명령, MCP 서버 연동 |
| 7 | 에이전트와 훅 | 서브에이전트, 자동화 훅 |
| 8 | 팀 협업과 운영 | 멀티 에이전트, 실전 운영 |

## 책 뷰어

실제 책처럼 두 페이지가 펼쳐지는 웹 뷰어입니다.

- **데스크탑**: 좌/우 두 페이지 스프레드 + 3D 책장 넘김 애니메이션
- **모바일**: 터치 스와이프로 페이지 전환
- **키보드**: `←` `→` 이전/다음, `Home`/`End` 처음/끝
- **목차**: ☰ 버튼으로 챕터·절 바로 이동
- **다크 모드**: 야간 독서 지원

### 로컬에서 열기

```bash
# book_viewer/index.html 더블클릭으로 즉시 실행 (서버 불필요)
```

### 원고 수정 후 뷰어 갱신

```bash
node book_viewer/build.mjs
```

## 기술 스택

| 영역 | 기술 |

| 집필 자동화 | Claude Code 에이전트 팀 (Opus 모델) |
